# ERL-HUB: Post-Earthquake Emergency Relief Logistics Hub

## Project Overview
ERL-HUB is a C++11-based project that simulates an emergency relief logistics system for managing supplies and dispatching relief vehicles after an earthquake.

## Concepts Used
- Classes and Objects
- Namespaces
- Function Overloading
- Dynamic Memory Allocation
- Inheritance and Polymorphism
- Operator Overloading
- Exception Handling
- File Handling
- Templates and STL

## Compilation
```bash
g++ -std=c++11 -Wall -Wextra -o erlhub erlhub.cpp
```

## Execution
```bash
./erlhub
```

The program demonstrates all four units of Object-Oriented Programming using C++.
